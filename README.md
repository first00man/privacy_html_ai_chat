# privacy_html_ai_chat
# تطبيق المحادثة الذكي مع Gemini AI 🤖

## 🌟 نظرة عامة
تطبيق ويب متكامل للمحادثة مع شخصيات ذكاء اصطناعي افتراضية يدعم نموذج Gemini من Google مع واجهة عربية كاملة.

## ✨ المميزات
- 🎭 إنشاء وإدارة شخصيات افتراضية مخصصة
- 💾 حفظ المحادثات محلياً (خصوصية كاملة)
- 🔐 استخدام مفتاح API الخاص بك
- 📱 تصميم متجاوب يعمل على جميع الأجهزة
- 🌐 واجهة عربية كاملة
- 📤 تصدير واستيراد المحادثات
- 🗃️ قاعدة بيانات محلية (IndexedDB)

## 🚀 التشغيل السريع
1. قم بتنزيل الملف `index.html`
2. افتحه في أي متصفح حديث
3. احصل على مفتاح API من [Google AI Studio](https://aistudio.google.com/apikey)
4. أضفه في تبويب "مفتاح API"
5. ابدأ المحادثة!

## 🛠️ التقنيات المستخدمة
- HTML5, CSS3, JavaScript (ES6+)
- IndexedDB (قاعدة بيانات محلية)
- Google Gemini API
- Tailwind CSS للتصميم
- Marked.js لتحويل النص
